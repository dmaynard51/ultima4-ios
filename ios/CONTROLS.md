# Ultima IV on iOS — Touch Controls

Hold the phone in **landscape**. The game runs at the classic 320×200, centred
with the controls in the side bars.

| Action | Touch |
|---|---|
| **Move** | On-screen **D-pad** (bottom-left) |
| **Commands** (talk, look, get, open, cast, ztats…) | Tap **⌨** to show the keyboard, then press the command letter |
| **Show/hide keyboard** | The **⌨** button (bottom-right) |
| **Confirm / advance text** | **↵** button, or Return on the keyboard |
| **Cancel / pass turn** | **Spc** button |
| **Back out of a menu** | **Esc** button |

Ultima IV is driven almost entirely by single-letter commands — e.g. `t`alk,
`l`ook, `g`et, `o`pen, `j`immy, `z` (ztats), `c`ast, `b`oard, `e`nter — so the
**⌨ keyboard button is your main tool**. Conversations are answered by typing
keywords (like `name`, `job`, `health`, `bye`).

When the keyboard is up, the game scales to stay fully visible above it, and the
buttons stay put; empty screen areas pass touches through to the game.

Your progress is saved automatically to the app's Documents folder.
